ふらっと。は、

障害者やその家族、

周りの人が心豊かに暮らすために、

外出・生活・制度などの情報を集約した

業界最大級のバリアフリー情報サイトです。

運営は、障害当事者やその家族、医療・福祉の専門職など、さまざまな人が関わり合って日々情報を発信しています。

当事者目線のリアルな情報が得られるので、より豊かな生活が手に入ります。

求めている情報が見つからないことで、

本人も周りも諦めてしまう、そんな世界を無くすために。

「行ける場所」で妥協するのではなく、

心から「行きたい！」と思えるおでかけを叶える。

「探している情報がここにあった！」

そう感じられるあたたかい場所にしていきます。

FEATURES ふらっとの特徴

  • 障害当事者や家族と共に運営

    障害当事者やその家族が取材・ライティング・校正/校閲・編集に参加。
    「行きたいのに情報がない」を、現場や当事者の経験や情報提供から解決していきます。

  • 【月間PV10万突破】WEBアクセシビリティにも真摯に向き合います。

    バリアフリー領域で業界最大級の閲覧数。
    「調べても出てこない」状態を、検索で見つかる情報資産に変えていきます。

■外出の選択肢を増やしたい方へ

  • 行きたい場所のバリアフリー情報を、事前に確認したい
  • 同じ立場の人が「実際に行った」場所を知りたい
  • 介助者・同行者として、行き先を一緒に検討したい
